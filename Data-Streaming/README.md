# Data Streaming
*****

The term "streaming" is used to describe continuous, never-ending data streams with no beginning or end, that provide a constant feed of data that can be utilized/acted upon without needing to be downloaded first.

****

- Amazon Kinesis
- Apache Kafka
- Apache Storm
- Spark streaming
- IBM Stream analytics
- Azure Stream Analytics
- Google Cloud DataFlow

# Data Streaming

This folder contains learning resources, streaming architectures, real-time data processing concepts, event-driven systems, message brokers, monitoring guides, interview questions, and hands-on projects related to Data Streaming technologies used in DevOps, Cloud, Big Data, and Modern Application Architectures.

Data Streaming enables real-time data processing, event handling, messaging, analytics, and communication between distributed systems and microservices.
