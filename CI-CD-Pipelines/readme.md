# CI/CD Pipelines

## Overview

CI/CD stands for:

- Continuous Integration (CI)
- Continuous Delivery (CD)
- Continuous Deployment (CD)

CI/CD helps automate the software development lifecycle including building, testing, and deploying applications.

---

## Benefits of CI/CD

- Faster software delivery
- Automated testing
- Reduced manual work
- Faster bug detection
- Improved deployment reliability
- Better collaboration between teams

---

## CI/CD Workflow

1. Developer pushes code
2. Code is built automatically
3. Automated tests run
4. Application is packaged
5. Deployment happens automatically

---

## Popular CI/CD Tools

- Jenkins
- GitHub Actions
- GitLab CI/CD
- ArgoCD
- CircleCI
- Tekton
